# Decisiones de Diseno y Arquitectura  Portafolio Profesional

## 1. Paleta de Colores
- **Color Primario (`hsl(220, 70%, 45%)`)**: Azul profesional que transmite confianza y sobriedad.
- **Color Fondo (`hsl(0, 0%, 98%)`)**: Blanco roto para reducir la fatiga visual.
- **Color Texto (`hsl(220, 15%, 20%)`)**: Gris oscuro con contraste verificado para cumplir normas WCAG AA.
- **Color Acento (`hsl(180, 60%, 45%)`)**: Turquesa para destacar botones y elementos interactivos.

## 2. Tipografia
- **Familia Principal**: `Inter`, sans-serif. Elegida por su alta legibilidad en pantallas digitales de cualquier resolucion.
- **Familia Monoespaciada**: `JetBrains Mono`, monospace para bloques de codigo o detalles tecnicos.

## 3. Maquetacion y Layout
- **Estructura**: HTML5 totalmente semantico (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- **CSS Layout**: Se utiliza Flexbox para la alineacion del menu/tarjetas y CSS Grid para la distribucion de los proyectos.
- **Enfoque Responsive**: Mobile-first para garantizar una correcta visualizacion desde 320px hasta pantallas 4K.
